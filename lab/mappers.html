gamutant.css’s lab

Gamut mapping, four ways

Each row is one hue at OKLCH chroma 0.4, lightness 0.04 to 0.98 left to right: more chroma than sRGB or Display P3 holds. The first strips clip each channel on its own, as a browser does today. Then gamutant.css’s .gamut-fit-screen with each --gamut-method, keeping the color’s hue; css, edge-seeker and ray-trace keep its lightness too, and adaptive gives some up toward the hue’s most colorful color. Under css and ray-trace, the same colors as Color.js 0.7.1 maps them, worked out when this page was built and written in as fixed colors. The page has no script.

On an sRGB screen, the Display P3 rows are clipped by the screen itself.
